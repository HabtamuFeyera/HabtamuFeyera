## 🚀 Featured Engineering Projects

### ⚖️ [Autonomous Contract Lawyer (Contract QA RAG)](https://github.com/HabtamuFeyera/contract_QA_Rag_project)
> *An intelligent legal intelligence assistant built to parse, query, and verify high-complexity contracts.*
* **Architecture**: Hybrid RAG pipeline combining hierarchical vector indexing with cross-encoder re-ranking to handle complex multi-page legal clauses without missing nuance.
* **Capabilities**: Strict citation generation, clause contradiction checks, and automated compliance risk scoring.
* **Tech Stack**: `Python`, `LangChain`, `Vector Database`, `FastAPI`, `Jupyter`

### 🕸️ [LangGraph Agent UI](https://github.com/HabtamuFeyera/langgraph-agent-ui)
> *A full-stack, real-time interface designed for stateful multi-agent orchestrations.*
* **Architecture**: Real-time websocket & streaming token delivery directly from cyclic LangGraph state machines.
* **Capabilities**: Visualized reasoning traces, execution state inspection, tool execution confirmation, and interactive human-in-the-loop overrides.
* **Tech Stack**: `Python`, `LangGraph`, `FastAPI`, `React`, `Modern UI`

### 🧠 [GenAI-Agents Modular Framework](https://github.com/HabtamuFeyera/GenAI-Agents)
> *A modular, extensible multi-agent execution framework engineered with structured thought-action loops.*
* **Architecture**: ReAct pattern-based agent architecture with custom tool registries, state management, and fallback error recovery mechanisms.
* **Capabilities**: Autonomous math verification, web extraction, external API integration, and self-correcting query decomposition.
